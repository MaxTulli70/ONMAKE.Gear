description: ONMAKE Gear. Use when a task starts, the kind of work changes, or a result is wrong: pick the lowest model and effort that still gives excellent quality, short peaks only for the essential step, STATO.md per job, REVERSE gear for errors. / Sceglie modello ed effort più bassi con qualità eccellente.
---

Follow the rule in `portabile/GEAR.md` (repository root). Levels LIGHT, MEDIUM, HIGH, OPUS (projects start here), MAX (single peak step); when in doubt go up, go down at once, even several levels, when the work gets simpler; peak only for the essential step; keep STATO.md per job; REVERSE starts at LIGHT. Prefer the agents by type of work (gear-reader, gear-tester, gear-editor, gear-writer, gear-debugger, gear-reviewer, gear-designer, gear-architect, gear-standards, gear-security). / Segui la regola in `portabile/GEAR.md`.
