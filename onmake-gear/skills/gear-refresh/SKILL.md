---
name: gear-refresh
description: Aggiorna ONMAKE Gear all'ultima versione (spegne, aggiorna dal repository, riaccende). / Refreshes ONMAKE Gear to the latest version.
disable-model-invocation: true
---

Run / Lancia: `sh "${CLAUDE_PLUGIN_ROOT}/scripts/riavvia.sh"`. Poi di' a Max in una riga: «Gear aggiornato, apri una chat nuova o riapri l'app per vedere la barra nuova» e la versione risultante.
