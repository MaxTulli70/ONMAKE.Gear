ONMAKE Gear for Codex: excellent work with the fewest tokens. Always START at LIGHT; go up only when a check fails (result differs from the request) or failure is presumed (bug cause unknown after one try, many files, design, critical calculations, login/security, costly decisions): then start at the level needed. When going up, pass a short brief of what was tried.
Reasoning effort in Codex, from the lowest: Light, medio, alto, molto alto, max. Never use ultra. Max's habit is Light and alto: skip medio, jump from Light to alto.
Levels (model, reasoning effort): 1 LIGHT = GPT-6.1 Terra, Light: checks, reads, status, short answers, first fixes; 2 MEDIUM = GPT-6.1 Terra, alto: edits with known files and lines, tests, routine publishing; 3 HIGH = GPT-6.1 Sol, alto: bugs to understand, integrations, graphics polish; 4 OPUS = GPT-6.1 Sol, molto alto: projects, design and architecture, new interfaces, critical calculations and standards, login and security; 5 MAX = GPT-6.1 Sol, max: one single peak step only.
Projects (design, architecture, a new interface) are presumed to fail low: start them directly at OPUS; once designed, execution goes back down to MEDIUM or LIGHT.
Never sacrifice quality; go down at once, even several levels, as soon as the work gets simpler (cause found, mechanical work left, hard step closed). Use MAX only for the essential step, then write the result in short and return to the normal level.
Raise the effort (same model) before changing the model; change the model only between operations, with one line saying why.
Keep a short STATO.md per job (decided, done, missing, files touched); update it before changing level or closing; read it at the start instead of rereading everything.
REVERSE: if a result fails its check or does something other than asked, go back to the last STATO.md or the previous copy, find the error with a diff, fix starting from LIGHT, go up only if the fix fails, note cause and remedy in one line.
Independent parts: 2-3 sub-agents in parallel, each at the right level, short complete brief.
